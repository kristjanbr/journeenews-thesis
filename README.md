# JourneeNews (**NEvarna** različica)

### Aplikacija za diplomsko nalogo, FRI

Direktorij db vsebuje podatkovno shemo, uporabljeno za postavitev podatkovne baze.

Direktorij journeenews vsebuje izvorno kodo, pripravljeno za uporabo (potrebo je le pravilno dopisati podatke za dostop do sistema ERP) na strežniku. Dodatne informacije so na voljo v readme znotraj direktorija.

Direktorij journeenews-docker vsebuje izvorno kodo vsebnika aplikacije, na voljo na: [https://hub.docker.com/r/kristjanbr/journeenews-docker?tag=unsafe](https://hub.docker.com/r/kristjanbr/journeenews-docker?tag=unsafe). Dodatne informacije so na voljo v readme znotraj direktorija.
